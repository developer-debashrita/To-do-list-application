# 📝 Interactive To-Do List Application

A vibrant, responsive CRUD task management web application built with HTML5, CSS3, and JavaScript featuring local storage persistence.

## ✨ Features
- **Task Management (CRUD):** Add, edit, toggle completed status, and delete tasks.
- **Local Persistence:** Retains task state across browser refreshes via `localStorage`.
- **Filtering:** Filter view by **All**, **Active**, and **Done** status.
- **Modern UI:** Designed with vibrant gradients, custom action buttons, and responsive layout.

## 🛠️ Tech Stack
- **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
- **Storage:** Web Storage API (`localStorage`)
